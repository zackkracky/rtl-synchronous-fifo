Hard requirements (the testbench is run by a script, so these are not optional):
1. Output exactly two files: fifo_tb_pkg.sv (package with all UVM classes) and tb_top.sv (top module).
2. Top module name: tb_top. Test class name: fifo_test. Instantiate the DUT as "dut" with DATA_WIDTH=8, DEPTH=16.

6. Run at least 2000 transactions with randomised wr_en, rd_en and din, then drop the objection.
7. Do not modify the DUT.

DUT specification:
- Synchronous FIFO, parameters DATA_WIDTH, DEPTH.
- Ports: clk, rst (active high, synchronous), wr_en, rd_en, din[DATA_WIDTH-1:0], dout[DATA_WIDTH-1:0] (registered), full, empty, overflow (registered, 1-cycle pulse), underflow (registered, 1-cycle pulse).
- A write is accepted when wr_en && (!full || rd_en). A read is accepted when rd_en && !empty.
- dout updates on the clock edge after an accepted read and holds otherwise.
- overflow pulses one cycle after a rejected write; underflow pulses one cycle after a rejected read.
- full = (occupancy == DEPTH); empty = (occupancy == 0).
